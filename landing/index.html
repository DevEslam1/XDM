Core Architecture

Engineered For Pure Throughput

No bloatware, no browser hijackers, no paywalls. Built from the ground up on Flutter 3 & custom Dart Isolate workers.

Pooled Isolate Multi-Segmenting

Breaks files into up to 16 dynamic byte ranges. All HTTP streaming and disk I/O are isolated on background CPU threads to guarantee 60/120 FPS UI smoothness.

Thread Workers (16x):

CRC32 Journal & Spot Check

Append-only journal file writes protect against sudden crashes or power cuts. Before resume, 64KB boundary spot-checking auto-heals corrupted segments.

HTTP/2 & HTTP/3 QUIC Probing

Intelligent host connection prober negotiates modern protocols via Cronet (Android) and Cupertino HTTP (iOS/macOS) for sub-millisecond TLS handshakes.

Bandwidth Governor & Schedules

Token-bucket rate limiter with per-domain limits, global download/upload caps, and automated overnight time-window scheduling.

Mirror Circuit Breakers

Supply multiple mirror URLs for a single file. XDM runs live latency checks and automatically fails over to the fastest healthy node.

App Lock & AES-256 Backups

Biometric & PIN lock, keychain credentials encryption, anti-fingerprinting automation cloak, and encrypted backup portability.
